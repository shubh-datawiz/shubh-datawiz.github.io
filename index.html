02 / Selected projects

Data products with a purpose.

DATA ENGINEERING / 01Databricks · OpenFDA

Pharmacovigilance data platform

A production-style data platform for FDA adverse-event data, designed to move messy API data into trusted analytical datasets. The project follows a medallion architecture and turns raw JSON into curated, query-ready tables for safety analysis and reporting.

  • Built resilient ingestion from OpenFDA with bronze, silver, and gold layers for traceable data movement.
  • Applied incremental processing, deduplication, validation checks, and Delta Lake patterns to improve reliability.
  • Modeled clean analytical tables that can support dashboards, trend analysis, and downstream BI consumption.
